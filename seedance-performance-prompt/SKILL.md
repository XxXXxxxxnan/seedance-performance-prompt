# Seedance 2.5 真实表演提示词

用户给出一个人物镜头（剧情、场景、视角、情绪轨迹均可），按本框架输出可直接粘贴进 Seedance 2.5 的中文提示词，再附简短测试建议。画幅不限，用户未指定时不写画幅。

## 三条核心理念

1. 演员演的是“对抗情绪”，不是情绪本身。写人物想要什么、在压抑什么，让情绪从细节里泄漏出来，不直接写“伤心”“高兴”。
2. 细节来自因果链：环境 → 身体 → 画面/声音。每个细节都要能追溯到一个环境或情绪原因。情绪叠加在生理反应之上，不替换它。
3. 节奏靠“紧迫目标 + 动作重叠 + 一个主停顿”。全片只保留一个有分量的停顿，其余动作用“同时 / 紧接着 / 随即”衔接。

## 工作步骤

### 1. 补全人物内心（三句话）
- 状态：身体处于什么条件
- 事件与压抑：发生了什么，他在压住什么情绪
- 紧迫目标：他必须马上去做什么（决定节奏）
用户没给的，按剧情合理补全，并在输出时一句话说明补了什么。

### 2. 确定视角与表演载体

| 视角 | 表演载体 | 镜头自身的作用 |
|---|---|---|
| 面部特写 | 眼周→口唇→下颌依次变化、视线、眨眼、表情不对称、皮肤状态 | 固定或极轻微呼吸感 |
| 中近景 | 面部 + 肩颈、呼吸起伏、手部小动作 | 基本稳定，可随重心轻微跟随 |
| 过肩/反打 | 被拍者面部为主；前景肩膀细微反应 | 固定，强调视线与关系 |
| 全身/中景 | 重心、步态、停顿、身体朝向 | 可跟随，节奏跟着人物 |
| 背影跟拍 | 肩背起伏、步伐变化、回头时机 | 跟随主角，晃动来自摄影者 |
| 第一视角 | 镜头停顿与晃动、双手、呼吸声与白气、焦点与视线落点 | 镜头即主角身体，所有运动来自身体 |
| 远景/全景 | 剪影姿态、动作节奏、与环境对比 | 稳定，环境承载情绪 |

载体转换规则：同一个物理反应在不同视角落在不同载体上。
- 第一视角 → 镜头运动、画面清晰度、双手、呼吸白气
- 面部特写 → 五官、皮肤、视线、眨眼
- 中近景/全身/背影 → 肩背、重心、步态、手部
- 远景 → 剪影的节奏与姿态
例：严寒颤抖——第一视角为镜头高频细微颤抖；面部特写为下颌轻颤、嘴唇发紫、鼻息白气；背影跟拍为肩膀缩紧发抖，镜头本身稳定。

### 3. 从条件库选物理因素，建立因果链
从下方《物理条件库》中选：
- 1 个主导因素：贯穿全程，写进“全程物理状态”
- 1–2 个辅助因素：在关键节拍中出现或偶发打断
- 1 个心理状态：叠加在生理反应之上
总数不超过 3 个环境/身体因素，否则模型顾此失彼。
每个因素写：身体反应 → 本视角载体上的画面表现 → 声音。再写一句因素间的相互作用（见条件库末尾）。

### 4. 规划节拍
- 时长 8–12 秒，约 4 个节拍；用户要求更长时可到 15 秒，每个情绪阶段不少于 1.5–2 秒。
- 标出唯一的主停顿（情绪冲击那一刻，1–1.5 秒），并写出停顿时生理反应的变化（如屏息时颤抖减弱）。
- 其余节拍动作重叠：前一个动作未结束，下一个已开始。
- 每个节拍包含三层：动作 + 物理反应在载体上的表现 + 对应声音。

### 5. 按模板写提示词

```
【总述】【视角/镜头类型】，一镜到底，写实电影质感，【拍摄方式：手持/固定机位/跟拍】，节奏紧凑。【时代与场景】，【天气与光线】。【色调，及唯一的强调色】。
主角状态：【身体条件】。
主角内心：【发生了什么】。【压抑的情绪】，但【紧迫目标】。

全程物理状态：
- 主导：【主导因素】导致【身体反应】，【本视角载体上的持续表现】；
- 辅助：【辅助因素】导致【身体反应】，【何时出现/如何打断画面】；
- 叠加：【因素间相互作用】；【情绪如何叠加在生理反应上】。

0–【t1】s：【建立画面与关键人物/物件，带时代与触感细节】。【情绪冲击】，【主停顿约1秒】，【停顿时生理反应的变化】。
【t1】–【t2】s：【释放停顿的动作】，【身体动作】的同时【下一个动作已开始】，紧接着【核心动作】，【受生理状态影响的动作质感】。
【t2】–【t3】s：【完成核心动作】，【物件的声音与质感反馈】。【一个短促的情绪动作，不停顿】。
【t3】–结尾：【起身/转身/抬头】的同时【视角或焦点转换】，【辅助因素/环境事件介入】，【揭示新信息】。主角随即【朝目标行动】。
结尾状态：【前景】，【背景】，【仍在持续的物理状态】。

表演控制：只在【主停顿时刻】停顿一次，其余动作连贯衔接、急而不乱；【本视角载体的运动规则】；【动作质感】；【需完全静止的对象及呈现基调】。
一致性：【人物/双手/服装】全程一致；【关键道具】形态一致；【环境、天气强度与光线】全程一致；【景别或机位要求】。
画质：真实摄影质感，可见【环境材质细节】、【物件材质细节】、【皮肤细节】。
声音：【环境底噪】，【呼吸与一次屏息】，【生理声音】，【动作声音】，【道具声音】，【远处声音】，【配乐要求】。
```

## 物理条件库

表中给出第一视角与面部特写两种载体；其他视角按“载体转换规则”换算。

|---|---|---|---|---|
| 火场/浓烟 | 呛咳、眼刺痛、压低身体 | 镜头放低贴近地面，烟雾遮挡，咳嗽时剧烈抖动，火光在边缘跳动 | 眼睛熏红流泪、脸上有灰、火光明暗闪动 | 噼啪燃烧声、剧烈咳嗽 |

| 黑暗 | 摸索、警觉、放慢动作 | 画面暗部大，仅局部光源照亮；手在前方探路，镜头缓慢转动 | 瞳孔放大、视线快速游移、屏息倾听 | 自己的呼吸被放大、细小环境声 |

| 颠簸交通工具 | 随车船晃动 | 画面随路面或浪涌有节奏地颠簸，抓扶手时手入画 | 身体随颠簸晃动，表情在晃动中保持稳定 | 发动机轰鸣、金属碰撞 |

### 心理状态（叠加层）

| 状态 | 身体反应 | 第一视角 | 面部特写 | 声音 |
|---|---|---|---|---|
| 恐惧 | 心跳加速、屏息、僵住 | 镜头突然静止，随后细微发抖；视线快速搜索四周 | 瞳孔放大、眉头上抬、嘴唇微张、颈部绷紧 | 心跳、屏住的呼吸 |
| 紧张焦虑 | 小动作多、呼吸浅 | 视线在几个点间频繁跳动，手指无意识摩挲物件 | 频繁眨眼、吞咽、抿唇 | 浅快呼吸、手指敲击 |
| 极度悲痛 | 身体发软、呼吸紊乱 | 镜头无力下沉，视线失焦，呼吸断续时画面顿挫 | 眉头内侧上抬聚拢→眼眶湿润→抿唇、下巴收紧起皱、下唇轻颤 | 被压住的抽泣气声 |
| 震惊 | 瞬间僵住、反应延迟 | 镜头完全静止约一秒，再缓慢移动 | 表情空白、眼睛睁大、嘴微张，反应慢半拍 | 环境声仿佛远去 |

### 因素相互作用（示例）
- 严寒 + 奔跑：喘息时白雾更浓，颤抖与喘息叠加
- 严寒 + 缺氧：动作稍做即喘，喘息加重颤抖
- 暴雨 + 受伤：雨水与视线模糊叠加，疼痛顿挫更明显
- 恐惧 + 黑暗：屏息时静止更突出，细小声音被放大
- 悲痛叠加在任何生理状态上：屏息时生理反应短暂减弱，呼气时加剧

## 写作规则

- 主角内心必须含“但”字句（情绪与目标的冲突）。
- 全程物理状态是持续“底噪”，不占节拍时长；辅助因素作为偶发事件打断节奏。
- 每个细节都落在本视角正确的载体上，不混用（第一视角不写主角的脸，背影跟拍不让镜头替主角发抖）。
- 用“试图……但……”写情绪泄漏；加入私人化小动作（如拂去对方脸上的雪），比大幅动作更有力。
- 面部表演：情绪按眼周→口唇→下颌依次传导，幅度控制在毫米级，额头等区域保持静止，表情轻微不对称（指定一侧先动）。可观察描述：真心笑=下眼睑上提、眼角细纹；勉强笑=只有嘴角动；悲伤开始=眉头内侧上抬聚拢；忍哭=下巴收紧起皱、抿唇、下唇轻颤；释怀=眉头舒展、长呼气。
- 泪光、汗珠、眼眶红润等物理细节写“从哪段出现→持续到哪里→如何减弱”，不突然出现或消失。
- 视线要有对象；眨眼与呼吸作为节奏器：忍泪时眨眼减少，一次缓慢眨眼常是转折点。
- 约束以正向描述为主，否定项只留最关键的 1–2 条。
- 画质写具体材质，不写泛泛的“高清”“电影感”。
- 声音与关键动作逐一对应，屏息、呼气、吞咽最能增强真实感。
- 时间戳只给关键节拍，必须写结尾状态。
- 涉及遗体或伤亡：姿态平静有尊严、无伤口血迹、基调庄重肃穆。

## 输出格式

1. 一句话说明视角、表演载体与所选物理因素（主导/辅助/心理），如有补全的内心设定也在此说明。
2. 完整提示词，放在代码块中。
3. 2–4 条测试观察点，从调试对照表挑相关的。

## 调试对照

| 问题 | 调整方式 |
|---|---|
| 节奏偏慢 | 删次要停顿，强化紧迫目标，串行动作改为“同时”发生 |
| 情绪太薄 | 主停顿延长到 1.5 秒，不另加停顿 |
| 物理反应过强（晃动、模糊过度） | 把“高频/剧烈”改为“轻微持续”，或减少辅助因素出现次数 |
| 物理反应不明显 | 把反应写进每个节拍，并配对应声音 |
| 画面混乱 | 物理因素减到主导 1 个 + 辅助 1 个 |
| 动作平滑像运镜 | 强调“镜头运动来自身体”“先停顿后动作” |
| 双手或人物变形 | 缩短片段，单独测试问题节拍 |
| 道具服饰不符合时代 | 上传参考图锁定 |
| 五官漂移 | 上传人物定妆图作首帧/角色参考，提示词只写表演 |
| 表演不像真人 | 上传真人表演视频作参考，写明“参考视频控制表情与节奏，参考图控制外形”，提示词只补参考里没有的内容 |

每次只改一个变量。

## 自检清单（输出前过一遍）

- 主角内心有“压抑 + 紧迫目标”的冲突
- 物理因素为 1 主导 + 1–2 辅助 + 心理叠加，总数不超标
- 每个细节可追溯到原因，且落在本视角正确的载体上
- 写了因素间相互作用与情绪叠加方式
- 主停顿只有一个，其余节拍用“同时/紧接着/随即”衔接
- 每个节拍含动作、物理表现、声音三层
- 写了结尾状态
- 需一致的人物、道具、环境都已点名
