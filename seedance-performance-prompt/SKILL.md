# Seedance 2.5 真实表演提示词

用户给出一个人物镜头（剧情、场景、视角、情绪轨迹均可），输出可直接粘贴进 Seedance 2.5 的中文提示词，再附简短测试建议。画幅不限，用户未指定时不写画幅。

## 文件导航

| 文件 | 何时读取 |
|---|---|
| `references/viewpoints.md` | 第 2 步：确定视角与表演载体；写面部表演时查微表情词汇 |
| `references/conditions.md` | 第 3 步：选物理因素（温度天气、身体状态、特殊空间、心理状态及其相互作用） |
| `references/debugging.md` | 写测试观察点，或用户反馈生成效果有问题时 |
| `examples/` | 第一次使用本 skill，或镜头类型与某个示例接近时，先读最接近的一个 |

示例清单：
- `examples/01-face-closeup-friend.md`：面部特写 · 窗边女性听老友提起已故母亲（克制→泄漏→释怀）
- `examples/02-pov-long-march-flag.md`：第一视角 · 红军长征雪山捡起战友的红旗（含 15 秒慢版 → 10 秒快版的节奏修改过程）
- `examples/03-pov-weishan-reeds.md`：第一视角·静 · 微山湖芦苇荡发现日军
- `examples/04-pov-machine-gun.md`：第一视角·动 · 捷克式轻机枪扫射
- `examples/05-pov-bayonet-duel.md`：第一视角·面对角色 · 白刃战（表演重心转到对手脸上）

## 三条核心理念

1. **演员演的是“对抗情绪”，不是情绪本身。** 写人物想要什么、在压抑什么，让情绪从细节里泄漏出来，不直接写“伤心”“高兴”。
2. **细节来自因果链：环境 → 身体 → 画面 / 声音。** 每个细节都要能追溯到一个环境或情绪原因。情绪叠加在生理反应之上，不替换它。
3. **节奏靠“紧迫目标 + 动作重叠 + 一个主停顿”。** 全片只保留一个有分量的停顿，其余动作用“同时 / 紧接着 / 随即”衔接。

## 工作步骤

### 1. 补全人物内心（三句话）
- 状态：身体处于什么条件
- 事件与压抑：发生了什么，他在压住什么情绪
- 紧迫目标：他必须马上去做什么（决定节奏）

用户没给的，按剧情合理补全，并在输出时一句话说明补了什么。

### 2. 确定视角与表演载体
读 `references/viewpoints.md`。核心规则：同一个物理反应在不同视角落在不同载体上（第一视角 → 镜头与双手；面部特写 → 五官与皮肤；背影 → 肩背与步态）。第一视角若正对另一个角色，微表情框架作用在**对手的脸上**。

### 3. 选物理因素，建立因果链
读 `references/conditions.md`，选：
- 1 个主导因素：贯穿全程，写进“全程物理状态”
- 1–2 个辅助因素：在关键节拍中出现或偶发打断
- 1 个心理状态：叠加在生理反应之上

环境 / 身体因素合计不超过 3 个。每个因素写清：身体反应 → 本视角载体上的表现 → 声音，并写一句因素间的相互作用。

### 4. 规划节拍
- 时长 8–12 秒，约 4 个节拍；更长可到 15 秒，每个情绪阶段不少于 1.5–2 秒。
- 标出唯一的主停顿（情绪冲击那一刻，1–1.5 秒），写出停顿时生理反应的变化（如屏息时颤抖减弱）。
- 其余节拍动作重叠：前一个动作未结束，下一个已开始。
- 每个节拍包含三层：动作 + 物理反应在载体上的表现 + 对应声音。
- “静”的镜头也要保留一个持续的微动源（船身起伏、呼吸），避免画面死静。

### 5. 按模板写提示词

```
【总述】【视角/镜头类型】，一镜到底，写实电影质感，【拍摄方式：手持/固定机位/跟拍】，节奏【紧凑/缓慢而紧绷】。【时代与场景】，【天气与光线】。【色调，及唯一的强调色】。
主角状态：【身体条件】。
主角内心：【发生了什么】。【压抑的情绪】，但【紧迫目标】。

全程物理状态：
- 主导：【主导因素】导致【身体反应】，【本视角载体上的持续表现】；
- 辅助：【辅助因素】导致【身体反应】，【何时出现/如何打断画面】；
- 叠加：【因素间相互作用】；【情绪如何叠加在生理反应上】。

【对手表演（仅当镜头正对另一角色时）：按眼周→口唇→下颌写出各节拍的面部变化】

0–【t1】s：【建立画面与关键人物/物件，带时代与触感细节】。【情绪冲击】，【主停顿约1秒】，【停顿时生理反应的变化】。
【t1】–【t2】s：【释放停顿的动作】，【身体动作】的同时【下一个动作已开始】，紧接着【核心动作】，【受生理状态影响的动作质感】。
【t2】–【t3】s：【完成核心动作】，【物件的声音与质感反馈】。【一个短促的情绪动作，不停顿】。
【t3】–结尾：【起身/转身/抬头】的同时【视角或焦点转换】，【辅助因素/环境事件介入】，【揭示新信息】。主角随即【朝目标行动】。
结尾状态：【前景】，【背景】，【仍在持续的物理状态】。

表演控制：只在【主停顿时刻】停顿一次，其余动作连贯衔接、急而不乱；【本视角载体的运动规则】；【动作质感】；【需完全静止的对象及呈现基调】。
一致性：【人物/双手/服装】全程一致；【关键道具】形态一致；【环境、天气强度与光线】全程一致；【景别或机位要求】。
画质：真实摄影质感，可见【环境材质细节】、【物件材质细节】、【皮肤细节】。
声音：【环境底噪】，【呼吸与一次屏息】，【生理声音】，【动作声音】，【道具声音】，【远处声音】，【配乐要求】。
```

## 写作规则

- 主角内心必须含“但”字句（情绪与目标的冲突）。
- 全程物理状态是持续“底噪”，不占节拍时长；辅助因素作为偶发事件打断节奏。
- 每个细节落在本视角正确的载体上，不混用（第一视角不写主角的脸，背影跟拍不让镜头替主角发抖）。
- 用“试图……但……”写情绪泄漏；加入私人化小动作（如拂去对方脸上的雪），比大幅动作更有力。
- 泪光、汗珠、眼眶红润等写“从哪段出现→持续到哪里→如何减弱”，不突然出现或消失。
- 视线要有对象；眨眼与呼吸作为节奏器。
- 写真实的时代细节（服装、武器、道具的具体名称与特征），并在测试建议中提示上传参考图锁定。
- 约束以正向描述为主，否定项只留最关键的 1–2 条。
- 画质写具体材质，不写泛泛的“高清”“电影感”。
- 声音与关键动作逐一对应，屏息、呼气、吞咽最能增强真实感。
- 时间戳只给关键节拍，必须写结尾状态。
- 战争、暴力、伤亡题材：遗体姿态平静有尊严；中弹只表现为扑倒；刺中只通过镜头受阻和表情表现；不写伤口、血迹特写；敌方角色按真实的人塑造，不脸谱化。测试建议中给出被平台拦截时的弱化写法。

## 输出格式

1. 一句话说明视角、表演载体与所选物理因素（主导 / 辅助 / 心理），以及补全了哪些设定。
2. 完整提示词，放在代码块中。
3. 2–4 条测试观察点，从 `references/debugging.md` 挑相关的。

多个镜头一起写时，统一主角双手、袖口等可见特征的描述，便于剪成一组。

## 自检清单（输出前过一遍）

- 主角内心有“压抑 + 紧迫目标”的冲突
- 物理因素为 1 主导 + 1–2 辅助 + 心理叠加，总数不超标
- 每个细节可追溯到原因，且落在本视角正确的载体上
- 写了因素间相互作用与情绪叠加方式
- 主停顿只有一个，其余节拍用“同时 / 紧接着 / 随即”衔接
- 每个节拍含动作、物理表现、声音三层
- 写了结尾状态
- 需一致的人物、道具、环境都已点名
