# 视角与表演载体

## 视角对照表

| 视角 | 表演载体 | 镜头自身的作用 |
|---|---|---|
| 面部特写 | 眼周→口唇→下颌依次变化、视线、眨眼、表情不对称、皮肤状态 | 固定或极轻微呼吸感 |
| 中近景 | 面部 + 肩颈、呼吸起伏、手部小动作 | 基本稳定，可随重心轻微跟随 |
| 过肩/反打 | 被拍者面部为主；前景肩膀细微反应 | 固定，强调视线与关系 |
| 全身/中景 | 重心、步态、停顿、身体朝向 | 可跟随，节奏跟着人物 |
| 背影跟拍 | 肩背起伏、步伐变化、回头时机 | 跟随主角，晃动来自摄影者 |
| 第一视角 | 镜头停顿与晃动、双手、呼吸声与白气、焦点与视线落点 | 镜头即主角身体，所有运动来自身体 |
| 第一视角·面对角色 | 主角：镜头、双手、呼吸；对手：完整面部微表情 | 镜头即主角身体；对手的脸是表演重心 |
| 远景/全景 | 剪影姿态、动作节奏、与环境对比 | 稳定，环境承载情绪 |

## 载体转换规则

同一个物理反应在不同视角落在不同载体上：

- 第一视角 → 镜头运动、画面清晰度、双手、呼吸白气
- 面部特写 → 五官、皮肤、视线、眨眼
- 中近景 / 全身 / 背影 → 肩背、重心、步态、手部
- 远景 → 剪影的节奏与姿态

例：严寒颤抖
- 第一视角：镜头高频细微颤抖，手指僵硬
- 面部特写：下颌轻颤、嘴唇发紫、鼻息白气
- 背影跟拍：肩膀缩紧发抖，镜头本身稳定

## 面部表演规则

- 情绪按 **眼周 → 口唇 → 下颌** 依次传导，不同步突变。
- 动作幅度控制在毫米级，额头、眉心、鼻翼等易“加戏”区域点名保持静止（除非该情绪需要它们动，如悲伤时眉头内侧）。
- 表情轻微不对称，指定一侧先动。
- 视线要有对象（看向谁/哪里）；回忆时视线下移、焦点变虚；压抑时视线回避；释怀时视线回到原处。
- 眨眼与呼吸是节奏器：忍泪时眨眼明显减少；一次缓慢眨眼常是情绪转折点；情绪涌上前常有一次屏息。

## 微表情词汇（可观察描述）

| 状态 | 写法 |
|---|---|
| 真心的笑 | 下眼睑上提、眼角出现细纹，不只是嘴角上扬 |
| 礼貌/勉强的笑 | 只有嘴角动，眼周不动 |
| 笑意消退 | 眼周的笑意先消失，嘴角还挂着 |
| 悲伤开始 | 眉头内侧轻微上抬并聚拢 |
| 忍泪 | 眼眶湿润反光、眨眼减少、眼睛睁得略久 |
| 忍哭 | 下巴肌肉收紧起皱、嘴唇抿紧、下唇轻颤、一次吞咽 |
| 愤怒压抑 | 眉头压低、下颌绷紧、鼻翼轻微扩张、嘴唇抿成一线 |
| 恐惧 | 瞳孔放大、眉头上抬、嘴唇微张、颈部绷紧 |
| 错愕 | 眼神一瞬停住、瞳孔微缩、动作中断 |
| 疼痛 | 眼周和一侧嘴角抽紧、倒吸气 |
| 释怀 | 眉头舒展、肩颈放松、一次较长的呼气 |
| 生命力流失 | 眼神失去焦点、下颌松开、力气从脸上一点点消失 |
