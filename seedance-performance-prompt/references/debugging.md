# 调试对照

每次只改一个变量，方便定位效果变化的原因。

## 节奏与情绪

| 问题 | 调整方式 |
|---|---|
| 节奏偏慢 | 删次要停顿，强化紧迫目标，串行动作改为“同时”发生；时长压到 10 秒、4 个节拍 |
| 情绪太薄 | 主停顿延长到 1.5 秒，不另加停顿 |
| 情绪像“换表情” | 把情绪名词改成潜台词与“试图……但……”句式 |
| 五官同步突变 | 重申“眼周→口唇→下颌依次变化”，每段只写一个部位先动 |
| “静”的镜头画面死静 | 补一个持续微动源（船身起伏、呼吸起伏、风吹发丝） |

## 物理反应

| 问题 | 调整方式 |
|---|---|
| 物理反应过强（晃动、模糊过度） | “高频/剧烈”改为“轻微持续”，或减少辅助因素出现次数 |
| 物理反应不明显 | 把反应写进每个节拍，并配对应声音 |
| 画面混乱 | 物理因素减到主导 1 个 + 辅助 1 个 |
| 动作平滑像运镜 | 强调“镜头运动来自身体”“先停顿后动作”“手持” |

## 画面与一致性

| 问题 | 调整方式 |
|---|---|
| 双手或人物变形 | 缩短片段，单独测试问题节拍 |
| 近距离对打时人物融合、刺刀穿模 | 先只测接触前的节拍；拉开两人初始距离 |
| 远景人物过大过近 | 加“人影很小，在画面远处” |
| 五官漂移 | 上传人物定妆图作首帧/角色参考，提示词只写表演 |
| 道具、服饰、武器不符合时代 | 上传参考图锁定（如捷克式轻机枪弹匣在枪身上方、红军军旗样式） |
| 敌方角色刻板化 | 上传面容参考图；写“按真实人物塑造，不脸谱化” |
| 表演不像真人 | 上传真人表演视频作参考，写明“参考视频控制表情与节奏，参考图控制外形”，提示词只补参考里没有的内容 |

## 平台审核

| 问题 | 调整方式 |
|---|---|
| 战争/暴力内容被拦截 | 去掉具体部位（“刺向胸前”→“刺向军官”）；中弹只写“扑倒”；遗体只写“静止、平静” |
| 遗体画面偏惊悚 | 加“画面基调庄重肃穆”，删去面部细节描写 |
