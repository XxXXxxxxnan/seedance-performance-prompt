# 示例 02 · 第一视角 · 长征雪山捡起战友的红旗

## 输入

> 镜头（第一视角·场景构图）：红军长征，主角低头，从一名冻死的红军战士遗体上捡起红旗。主角抬头，远处是漫天风雪中逶迤向前的红军队伍。

## 选择说明

- 视角载体：镜头的停顿与晃动、双手、呼吸声与白气、焦点转移（主角的脸不入画）
- 主导因素：严寒 → 镜头高频细微颤抖、手指僵硬
- 辅助因素：高原缺氧（画面随喘息起伏）、风雪（阵风推镜头、雪粒打镜头）
- 心理叠加：悲痛——屏息时颤抖短暂减弱，呼气时加剧
- 补全设定：倒下的是一路同行的战友；紧迫目标是“队伍正在远去，必须马上带着旗跟上”

## 修改过程（节奏）

第一版 15 秒有 5 个独立节拍，认出、默哀、起身各停顿一次，动作串行，节奏偏慢。
修改为 10 秒 4 个节拍：
- 只保留“认出战友”一个主停顿
- 跪下的同时手已伸出；拂雪一下就去掰手指
- 起身的同时抬头，红旗在起身过程中被风展开
- 生理细节统一写进“全程物理状态”，不占节拍时长

## 提示词（10 秒定稿）

```
第一人称主观视角，一镜到底，写实电影质感，全程手持拍摄，节奏紧凑。红军长征途中，海拔四千米的雪山垭口，暴风雪，阴天冷灰色漫射光。画面低饱和蓝灰色调，红旗是唯一的鲜艳颜色。
主角状态：极度寒冷、饥饿、缺氧，体力接近极限。
主角内心：倒下的是一路同行的战友。悲痛涌上来，但队伍正在远去，风雪越来越大，他必须马上带着旗跟上去。

全程物理状态：
- 主导：严寒导致主角持续寒颤，镜头始终带有细微高频颤抖，手指僵硬迟缓；
- 辅助：缺氧导致呼吸急促，画面随呼吸起伏，每次呼气白气从画面下缘升起被风吹散；阵风不时把镜头推得一晃；
- 叠加：屏息时颤抖短暂减弱，颤抖的呼气后颤抖加剧。

0–2s：视角低垂快速扫过雪地，停在一名背靠岩石的年轻红军战士身上：单薄的灰色单衣，绑腿，磨破的草鞋，身上积着薄雪，眉睫结霜，面容平静，冻白的双手紧握一面卷起的红旗。主角认出了他，呼吸骤然屏住，镜头静止约一秒，颤抖短暂减弱。
2–5s：一声颤抖的呼气，主角双膝跪进深雪，镜头随之下沉摇晃，同时双手已伸入画面：缠着破布条，指节冻裂。他用手背快速拂去战士脸上的雪，紧接着去掰战士冻僵的手指，手抖得厉害，需要用力。
5–7s：他抓住旗杆一把抽出，冻硬的旗面发出脆响，积雪簌簌掉落。镜头短促地低了一下，像是无声的告别。
7–10s：他拄着旗杆猛地起身，腿一软镜头晃了一下随即稳住，同时视角抬起。一阵强风迎面扑来，雪粒打在镜头上，冻硬的红旗在前景被风猛然抖开。远处风雪中，红军队伍沿着雪山山脊逶迤向前，人影细小，互相搀扶，深一脚浅一脚。主角立刻向队伍迈步，镜头陷进雪里又抬起。
结尾状态：前景红旗猎猎展开，镜头带着寒颤和喘息朝远处队伍追去。

表演控制：只有认出战友时的一次停顿，其余动作连贯衔接、急而不乱；镜头运动全部来自主角身体，无平滑运镜；双手僵硬颤抖；遗体全程完全静止，姿态平静有尊严，无伤口血迹，基调庄重肃穆。
一致性：主角双手、布条、灰色军装袖口全程一致；红旗形态一致；风雪与光线全程一致。
画质：真实摄影质感，可见飞雪颗粒、睫毛霜花、布料冰碴、冻裂皮肤纹理。
声音：呼啸风声，急促呼吸与一次屏息，隐约的牙齿打颤声，跪雪与踩雪的闷响，旗面脆响和随后的猎猎扑动声，远处隐约脚步声，无配乐。
```

## 测试观察点

- 若仍偏慢，删掉 5–7s 的“镜头低了一下”，悲痛完全由屏息承担
- 若情绪太薄，把屏息延长到 1.5 秒，不在别处加停顿
- 若晃动过强，“细微高频颤抖”改为“轻微持续颤抖”
- 红军军旗样式建议上传参考图锁定
