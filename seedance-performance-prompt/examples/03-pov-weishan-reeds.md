# 示例 03 · 第一视角·静 · 微山湖芦苇荡发现日军

## 输入

> 镜头（第一视角·静）：微山湖游击队，主角趴在行进小船上，拨开芦苇荡，看见远处日军。

## 选择说明

- 视角载体：镜头起伏、左手拨芦苇、呼吸声
- 主导因素：小船随水起伏 → 镜头缓慢上下摇摆，视线贴近水面
- 辅助因素：清晨露水与芦苇刮擦 → 水珠洒落在手背和镜头上
- 心理叠加：紧张警觉——屏息时主角身体静止，但船身仍在起伏，画面无法完全停住
- 补全设定：黎明薄雾；敌人是湖堤上的巡逻队；紧迫目标是“看清敌情且不被发现”，所以节奏慢而紧
- 要点：“静”的镜头必须保留持续微动源（船身起伏），否则模型会做成死静的画面

## 提示词

```
第一人称主观视角，一镜到底，写实电影质感，低机位手持，节奏缓慢而紧绷。抗日战争时期，微山湖，黎明，湖面笼着薄雾，冷青色晨光。画面低饱和青灰色调，远处日军钢盔与刺刀的反光是唯一的亮点。
主角状态：游击队员，彻夜潜伏，全身被露水打湿，身体紧贴船板。
主角内心：情报说日军巡逻队就在附近。他紧张得心跳很快，但必须看清敌人的人数和动向，一点声音都不能出。

全程物理状态：
- 主导：小船在水面缓慢起伏，镜头始终随船身轻微、缓慢地上下摇摆，视线很低，几乎贴着船帮和水面；
- 辅助：芦苇上挂满露水，拨动时水珠洒落在手背和镜头上；芦苇叶刮过船帮发出沙沙声；
- 叠加：屏息时主角身体完全静止，但船身仍在轻微起伏，画面无法完全停住。

0–3s：视角低，紧贴船帮。前方是密密的芦苇，叶片上挂着露水，薄雾在苇杆间缓慢流动。主角的左手伸入画面，手背被水泡得发白，袖口是打着补丁的粗布，手指慢慢搭上一丛芦苇。右手压在船板上的汉阳造步枪上，画面下缘能看到枪托。
3–6s：左手极慢地向一侧拨开芦苇，露水簌簌洒落，几滴打在镜头上，画面局部短暂模糊又恢复。芦苇被拨开一道缝的同时，视角微微向前探。
6–8s：缝隙中，远处湖堤上，一队日军巡逻兵正沿堤岸行进：土黄色军装，钢盔，步枪上的刺刀在晨光中一闪一闪。主角呼吸骤然屏住，左手停在半空，画面静止约一秒，只剩小船轻轻起伏。
8–10s：一声极轻、极慢的呼气，左手缓缓松开，芦苇慢慢合拢，日军身影被苇叶一点点遮住。视角同时向下压低，贴回船帮。
结尾状态：画面被芦苇重新遮住，只从苇叶缝隙间隐约透出远处堤岸，小船仍在缓慢起伏。

表演控制：只在看到日军时停顿一次；所有手部动作极慢、极轻，体现不敢发出声音；镜头运动来自船身起伏和主角身体，不出现平滑推拉。
一致性：主角左手、补丁袖口、步枪全程一致；薄雾浓度与晨光全程一致；日军服装形态一致。
画质：真实摄影质感，可见芦苇叶上的露珠、水面细小波纹、被水泡皱的手背皮肤、粗布纹理。
声音：湖水轻拍船帮，芦苇沙沙声，露水滴落水面的细响，主角压低的呼吸和一次屏息，远处隐约的日军脚步声和口令声，水鸟偶尔一声啼叫，无配乐。
```

## 测试观察点

- 注意船身起伏是否保留，若画面死静，强化“镜头始终随船身起伏”
- 远处日军可能过大过近，必要时加“人影很小，在画面远处”
