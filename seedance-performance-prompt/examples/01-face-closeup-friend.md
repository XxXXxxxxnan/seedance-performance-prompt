# 示例 01 · 面部特写 · 老友提起已故母亲

## 输入

> 胸像特写，一位女性坐在窗边和老朋友聊天，朋友提起了她已故的母亲。情绪：克制的高兴 → 迟疑 → 伤心 → 强忍 → 含泪释怀。

## 选择说明

- 视角载体：面部（眼周→口唇→下颌）、视线、眨眼、呼吸
- 物理因素：无强烈环境因素；心理状态为“悲痛 + 不想失态”，用屏息、吞咽、眨眼减少承担
- 补全设定：视线对象为镜头左侧的老朋友；紧迫目标是“不想在朋友面前失态”
- 要点：情绪从眼神开始泄漏——嘴角还挂着笑，眼周的笑意已经消失；表情不对称，右侧先动

## 提示词

```
胸像特写人物表演，一镜到底固定机位，写实电影质感。一位三十岁左右的女性坐在窗边，午后柔和侧光。
人物视线对象：镜头左侧一位多年未见的老朋友。
人物内心：朋友提起了她已故的母亲。悲伤涌上来，但她不想在朋友面前失态。

0–2s：她带着真心的笑听对方说话，下眼睑上提，眼角有细纹。
2–4s：她试图保持笑容，但眼神先停住，焦点变虚，视线轻微下移；嘴角还挂着笑，眼周的笑意已经消失。
4–6s：眉头内侧轻微上抬聚拢，眼眶开始湿润反光；眨眼明显减少，有一次短暂屏息。
6–8s：她抿紧嘴唇，下巴轻微收紧，右侧嘴角轻颤；做一次吞咽，视线短暂移向窗外。
8–10s：一次缓慢的眨眼后，她长长呼气，肩膀放松，视线回到朋友身上，嘴角极轻地上扬。
结尾状态：她平静地看着朋友，眼中仍留着淡淡的泪光，带着一点温柔。

表演控制：情绪从眼神开始，依次传到口唇和下颌；表情轻微不对称，右侧先动；动作控制在毫米级，额头保持静止。泪光不滑落，结尾缓慢减弱。
一致性：人物、服饰、背景与光线全程一致；固定机位，景别恒定。
画质：真实摄影质感，保留毛孔、细小汗毛与发丝细节。
声音：安静室内底噪，一次屏息、一次吞咽、一次长呼气，无配乐。
```

## 测试观察点

- 上传人物定妆图锁定长相，提示词里不再描述五官
- 若五官同步突变，重申“眼周→口唇→下颌依次变化”
- 若泪水滑落，强化“泪光停留在眼眶，不滑落”
