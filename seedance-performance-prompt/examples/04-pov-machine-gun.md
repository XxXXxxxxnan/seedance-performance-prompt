# 示例 04 · 第一视角·动 · 捷克式轻机枪扫射

## 输入

> 镜头（第一视角·动）：战场，主角端着捷克式轻机枪，向日军扫射。

## 选择说明

- 视角载体：后坐力带来的镜头震动、枪身与双手、枪口焰与硝烟
- 主导因素：连续射击的后坐力 → 镜头随点射震动，枪口上跳后被压回
- 辅助因素：硝烟扬尘遮挡视线；枪管发热，上方空气扭曲
- 心理叠加：愤怒决绝 + 紧张——射击时憋气，点射间隙急促换气
- 补全设定：华北平原土坡阵地；紧迫目标是“压住日军冲锋，掩护战友转移”
- 真实细节：捷克式轻机枪弹匣在枪身上方，视线从枪身左侧看出；弹匣仅 20 发，打两三个点射就要换——把**空仓换弹匣**设为唯一主停顿

## 提示词

```
第一人称主观视角，一镜到底，写实电影质感，手持，节奏急促。抗日战争时期，华北平原上的土坡阵地，午后，硝烟弥漫，灰黄色日光。画面低饱和土黄色调，枪口焰是画面中最亮的颜色。
主角状态：激战已久，满身尘土，双臂因持续射击而酸胀。
主角内心：日军正在冲锋，战友在侧翼转移。他心里又急又怒，但必须压住敌人，一刻都不能停火。

全程物理状态：
- 主导：每次点射，镜头随后坐力高频剧烈震动，枪口持续上跳，主角用力把枪压回；
- 辅助：硝烟和扬尘不时飘过画面遮挡视线；枪管散发热气，枪管上方的空气微微扭曲；
- 叠加：射击时呼吸憋住，点射间隙才急促换气，画面随换气起伏。

0–3s：主角从战壕边猛地站起，双手端起捷克式轻机枪抵肩，镜头随起身晃动后稳住。画面中央是枪身，弹匣竖立在枪身上方，视线从枪身左侧望出去：远处田野上，一群日军正弯腰冲锋，身影在硝烟中时隐时现。主角立刻开火，枪口焰闪烁，镜头随后坐力剧烈震动，空弹壳从枪身下方连续弹出。
3–6s：第一个点射结束，主角急促吸一口气，同时把上跳的枪口压回，紧接着打出第二个点射。远处冲在前面的几名日军扑倒在地，其余的趴下躲避。一阵硝烟飘过画面，视线短暂变灰。
6–8s：第三个点射打到一半，枪声戛然而止，只剩一声空仓的金属轻响。画面静止约一秒，主角的喘息声突然清晰。随即他左手猛地拔下空弹匣，扔向一边，从腰间抽出新弹匣插上，手因用力而发抖。
8–10s：新弹匣插好的同时，枪口已重新抬起对准前方，他再次开火，镜头随后坐力剧烈震动，枪管上方的热气更加明显。
结尾状态：枪口焰持续闪烁，硝烟中远处日军被压制在地面，镜头带着后坐力的震动继续射击。

表演控制：只在空仓时停顿一次，其余动作连贯衔接、急而不乱；镜头震动全部来自后坐力和主角身体，点射之间有清晰的节奏间隔；远处中弹的日军只表现为扑倒，不出现血腥特写。
一致性：主角双手、袖口、捷克式轻机枪（弹匣在枪身上方）全程一致；硝烟浓度与光线全程一致。
画质：真实摄影质感，可见枪身的金属磨损与烤蓝、双手上的尘土与擦伤、飞扬的尘粒、硝烟的颗粒感。
声音：捷克式轻机枪清脆连贯的“哒哒哒”点射声，弹壳落在土上的叮当声，空仓的金属轻响，拔插弹匣的咔嗒声，主角憋气后急促的喘息，远处日军的喊叫与零星枪声，射击后短暂的轻微耳鸣，无配乐。
```

## 测试观察点

- 捷克式轻机枪外形单靠文字容易画错，建议上传枪械参考图
- 若震动太强看不清，“高频剧烈震动”改为“随点射有节奏地震动”
