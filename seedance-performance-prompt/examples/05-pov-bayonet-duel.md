# 示例 05 · 第一视角·面对角色 · 白刃战

## 输入

> 镜头（第一视角·面对角色）：战场，白刃战，主角端着步枪刺刀，刺向一名日本军官。

## 选择说明

- 视角载体：主角由镜头、双手、呼吸承担；**表演重心转到对手脸上**，微表情框架完整作用在军官身上
- 主导因素：肉搏的体力消耗 → 镜头随沉重喘息起伏，动作带用尽全力后的晃动
- 辅助因素：硝烟扬尘在两人之间飘过
- 心理叠加：生死一搏的决绝与恐惧——刺出前屏息，刺中后爆发粗重呼气
- 补全设定：子弹打光；军官按历史持军刀，先劈砍、被格挡，再被刺中
- 处理原则：刺中只通过镜头受阻和军官表情表现，不写伤口和血；军官按真实的人塑造，不脸谱化——兼顾冲击力与平台审核

## 提示词

```
第一人称主观视角，一镜到底，写实电影质感，手持，节奏急促。抗日战争时期，炮火过后的村口阵地，阴天，硝烟弥漫，灰暗漫射光。画面低饱和灰褐色调。
主角状态：已经拼杀多时，体力透支，满脸尘土，大口喘气。
主角内心：子弹打光了，迎面冲来一名日军军官。他心里也怕，但退无可退，必须先刺倒对方。

全程物理状态：
- 主导：体力透支，镜头随沉重的喘息明显起伏，每个动作都带着用尽全力后的晃动；
- 辅助：硝烟和扬尘在两人之间飘过；
- 叠加：刺出前一瞬屏住呼吸，刺中后才爆发出一声粗重的呼气。

军官表演（面部，按眼周→口唇→下颌依次变化）：
- 劈砍时：眼睛睁大、眉头压低紧锁，嘴张开发出喊声，下颌绷紧；
- 被格挡后：眼神先出现一瞬错愕，瞳孔微微收缩，喊声中断；
- 被刺中时：眼睛猛然睁大，眉头内侧上抬，嘴张开却发不出声音，下颌松开；
- 倒下时：眼神失去焦点，力气一点点从脸上消失。

0–2s：硝烟中，一名日军军官迎面冲来：军帽，领章，皮质武装带，双手高举军刀，嘴里喊着。主角双手端着上了刺刀的汉阳造步枪，刺刀尖在画面下方中央，镜头随喘息起伏。
2–4s：军官的军刀当头劈下，主角横枪向上一格，刀刃砍在枪身上，金属撞击声刺耳，镜头被这一刀震得猛然一沉。军官的眼神在这一瞬出现错愕。
4–6s：主角屏住呼吸，借着格开的力量向前猛地一突，刺刀直刺军官胸前。镜头向前冲出，随即受阻骤然停住。画面静止约一秒：两人距离极近，军官的脸占据画面，眼睛猛然睁大，嘴张着却发不出声音，军刀从手中滑落。
6–8s：主角爆发出一声粗重的呼气，双手用力向后抽枪，镜头随之后撤晃动。军官的眼神失去焦点，膝盖一软，向前跪倒，倒出画面下方。
8–10s：主角几乎没有停顿，视角立刻抬起、转向一侧，硝烟中又有人影冲来，他喘着粗气重新端平刺刀。
结尾状态：刺刀重新指向前方，镜头随剧烈的喘息起伏，硝烟中新的人影逼近。

表演控制：只在刺中后停顿一次，其余动作连贯、凶猛、急而不乱；镜头运动全部来自主角身体，格挡与刺中都有明显的受力顿挫；刺中只通过镜头受阻和军官表情表现，不出现伤口、血迹特写；军官按真实的人物塑造，不做脸谱化处理。
一致性：主角双手、袖口、带刺刀的步枪全程一致；军官面容、服装、军刀全程一致；硝烟与光线全程一致。
画质：真实摄影质感，可见军官脸上的尘土与汗水、皮肤毛孔、军服布料纹理、刺刀与军刀的金属反光、空气中的尘粒。
声音：远处断续的枪炮声，军官的喊声，刀与枪身撞击的刺耳金属声，主角憋住的呼吸和刺中后粗重的呼气，军刀落地的声响，军官倒地的闷响，持续的喘息，无配乐。
```

## 测试观察点

- 面对面近距离动作容易人物融合或刺刀穿模，先只测 0–6s
- 军官面容建议上传参考图锁定，避免刻板形象
- 若平台拦截，“刺向胸前”改为“刺向军官”
- 与示例 03、04 连剪时，统一主角“打着补丁的粗布袖口、手背有擦伤”
